ONLINE FASHION FOOTWEAR HUB - REDTAPE WEBSITE
==============================================

Pages included:
1. index.html       - Home
2. products.html    - Product listing, search and filters
3. categories.html  - Product categories
4. product.html     - Product detail
5. cart.html        - Shopping cart using localStorage
6. checkout.html    - Checkout form
7. login.html       - Customer login demo
8. register.html    - Customer registration demo
9. orders.html      - Orders / tracking page
10. about.html      - Project introduction
11. contact.html    - Contact/enquiry page

Assets:
- style.css
- script.js

HOW TO RUN:
1. Extract the ZIP.
2. Open index.html in Chrome.
3. For your college XAMPP project, copy the folder into:
   C:/xampp/htdocs/online_fashion_footwear_hub/
4. Visit:
   http://localhost/online_fashion_footwear_hub/

BACKEND NOTE:
The documentation specifies PHP + MySQL + XAMPP/Apache. This version is a complete multi-page front-end prototype with cart persistence. Real login, registration, products, orders, payment and admin functions should be connected to MySQL using PHP.
