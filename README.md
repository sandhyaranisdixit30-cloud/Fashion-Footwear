# REDTAPE Footwear Hub

A responsive front-end footwear shopping website built with HTML, CSS and JavaScript.

## Updated product experience
- 24 real-image footwear styles: 8 Women + 8 Men + 8 Kids.
- Every product has multiple size options.
- Every product has multiple color swatches.
- Click a color swatch to instantly change the displayed shoe preview color.
- Selected size + color are stored in the cart and shown in checkout, orders and tracking.
- Product detail pages include live color switching and size selection.
- Cart, delivery address, demo payment, order confirmation, tracking and reviews use browser localStorage.

## How to open
1. Extract the ZIP.
2. Open `START_HERE.html` or `index.html` in Chrome/Edge.
3. Internet access is recommended because the footwear photos are loaded from Unsplash.

## Important
This is a front-end/demo shopping website. Login, registration and payment are simulated locally. For production use, connect a secure backend, database, authentication system and real payment gateway.


Image cleanup update: product and category imagery was replaced with shoe/sneaker-focused Unsplash photographs so faces/people are not used as footwear images.
